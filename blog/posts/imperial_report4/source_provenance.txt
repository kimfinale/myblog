Published derivative: traveller-followup.tsv
Encoding: UTF-8, without BOM; tab separated; LF line endings; header row.
Missing outcome times use literal NA. Boolean values use TRUE and FALSE.
One row represents one recorded traveller case. No identifier, source URL
for an individual, date, age, sex, nationality, or location is retained.
Rows are sorted by the four retained fields rather than source record order.
This file contains historical follow-up observations, not simulated cases.

Transformation
1. Parse relevant source dates using day/month/year, treating blank and NA
   fields as missing.
2. Use date_onset_symptoms_dd_mm_yyyy when observed.
3. If onset is missing, use the earliest available value among
   date_hospitalized_dd_mm_yyyy, date_report_dd_mm_yyyy, and
   date_confirmed_dd_mm_yyyy. This reproduces the latest-possible-onset
   imputation described in Report 4, page 8. No onset is imputed from travel.
4. Set followup_days to 2020-02-08 minus the observed or imputed onset date.
5. A death or recovery dated on or before 2020-02-08 defines outcome as
   death or recovery, respectively. Other records are unresolved at cutoff.
6. Set outcome_days to the event date minus the onset date for observed
   deaths and recoveries; use NA for unresolved records.
7. Set onset_imputed to TRUE only when step 3 was required.
8. Remove all other source fields and discard source row order.

Calendar-day convention
The retained times are integer differences between calendar dates, not
inclusive day counts. A case with onset on 8 February has followup_days=0.
No subdaily event times or exact censoring times are available in the source.
For a likelihood treating each reported event date as the interval
[outcome_days, outcome_days + 1), an inclusive end-of-8-February cutoff
corresponds to unresolved survival through followup_days + 1. The TSV
preserves the requested unadjusted date difference so the downstream
analysis can state its chosen within-day convention. A calculation using
survival at followup_days instead places censoring at the start of the
cutoff date and is a distinct approximation.

Validation
Rows: 290
Observed onset: 149
Imputed onset: 141
Deaths by cutoff: 2
Recoveries by cutoff: 36
Unresolved at cutoff: 252
Recovered cases with observed onset: 29
Follow-up ages: 0 to 39 days; all nonnegative
All observed event ages are nonnegative and no later than followup_days.
The 29 observed onset-to-recovery intervals are consistent with the smaller
sample mentioned in Methods A and Table 2 (page 7), while Table 1 describes
36 recovered cases; the report does not explicitly document that selection.
Fixed delay parameters and these data alone do not
reproduce the report's posterior integration or published intervals.
